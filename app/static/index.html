What the app does

Use Check a sequence to evaluate one sequence, Design a peptide to search for a low-energy sequence in one environment, Create a family to generate several diverse candidates, Compare environments to inspect the same sequence in two environments, Design for selectivity to design one-vs-rest selective candidates, and Design for two environments to search for trade-offs between environments.

How to read the results

Lower model energy means better compatibility with the chosen helical state within the model. These energies are reported in dimensionless Hamiltonian units , not in physical units such as kcal/mol, so they should be interpreted comparatively within the same scoring setup. A more negative Z-score means the sequence is better than the random-sequence background. Percentile tells you where the sequence sits relative to that random ensemble, with lower being better. Net charge follows the current model convention; in this version histidine is treated as neutral in the charge-dependent terms.

What environments mean

Homogeneous polar approximates a water-like medium. Homogeneous apolar approximates a non-polar medium. Interfacial modes impose a membrane-facing and water-facing sector on the helical wheel, plus an anionic, neutral or cationic membrane surface charge. In the app, penetration depth is a percentage with the same meaning in every panel: 0% is the homogeneous polar medium, 100% the homogeneous apolar medium, and intermediate values use the interfacial preset with an apolar sector half-width of 40° + 1.1° per percent. It is an angular exposure setting, not a physical insertion depth. In interfacial environments, scoring and design both align each sequence by its own hydrophobic moment toward the apolar sector. Calibration and random reference sequences follow the same rule. If the hydrophobic moment vanishes, the preset wheel phase is used. Orientation has no effect in homogeneous media.

In the workspace, “Non-polar exposure” and “Explore exposure” refer to the original penetration-depth setting: an angular exposure coordinate, not a physical insertion depth. Interface labels indicate membrane surface charge.

What λgap means

λgap is only used in Design for two environments . It penalizes sequences that behave very differently in the two chosen environments. Small values favor the best overall compromise; larger values push the search toward more balanced cross-environment compatibility.

Hamiltonian terms
H = λ env H env + λ chg H chg + λ local H local + λ pair H pair + λ elec H elec + λ neigh H neigh

Environment rewards residues that match the target medium. Charge captures residue preference with membrane surface charge. Local helix and Helix neighbors reward helical propensity. Pairwise adds sequence-dependent interaction preferences. Electrostatics captures attractive and repulsive charge interactions along the helix. The transverse hydrophobic moment is a geometric descriptor displayed on the helical wheel and used for interfacial alignment. It is not an energy term. Histidine contributes through the hydrophobicity and helical-propensity terms and is neutral in the charge-dependent terms.

API and programmatic examples

Use the HTTP API to run scoring, sequence design, environment comparisons and exposure scans from scripts. Open interactive API documentation , download the OpenAPI schema , or follow the API guide with curl and Python examples . Check the serving version in the schema and retain each result's provenance when reporting calculations.

Practical limitations

The model scores compatibility with a predefined helical scaffold. It is best interpreted as a relative design and ranking tool. Experimental activity, folding kinetics, insertion depth and membrane disruption require additional validation.

How is selectivity calculated?
The specificity target is L λ = λH target + (1-λ)(H target - min(H off-targets )) . Lower values are better. Use λ = 0 for the hard one-vs-rest limit, and larger λ values when you want to give progressively more weight to absolute target favorability.
